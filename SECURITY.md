# Security policy

Please do not report vulnerabilities in public issues.

Use [GitHub private vulnerability reporting](https://github.com/2kims/lotor-go/security/advisories/new)
and include the affected version, impact, reproduction steps, and any proposed
mitigation. Do not include real customer credentials or production data.

Only the latest release-candidate or stable `v0.1.x` version is supported while
the SDK remains pre-1.0.
